详情

感恩乔帮主，自荐 vibe 的 mac 智能剪贴板 APP

----
Echo 是一款原生 Mac 菜单栏剪贴板工具，从找回内容，到整理、提问，再到粘贴使用，在同一个面板里完成，目前支持：
- 剪贴板历史：自动记录文本、图片和 Finder 文件，快捷键呼出，输入关键词即可查找。
- Markdown

轻量 macOS 剪贴板管理器 · 智能查找 / 秒级检索 / 一键粘贴. Contribute to akira82-ai/echo-app development by creating an account on GitHub.
